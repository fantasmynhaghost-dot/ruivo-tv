# RuivoTV Demo Add-on

Pacote declarativo de demonstração embutido no app para testar instalação local, catálogo, filtros, agrupamento de episódios e estado do player.

**Todos os títulos, canais, sinopses e horários são fictícios.** As URLs usam `example.org` com caminhos inexistentes, não fornecem vídeo e não representam conteúdo ou serviço real. Não substitua essas URLs por fontes sem autorização.

O pacote contém somente `manifest.json`, `catalog.json` e este README. Não contém código executável, JavaScript, HTML, APK ou bibliotecas.
